Sobre lista encadeada
Recomendações: 
- Em Python, construa os nós e a lista com classes, sem usar list como armazenamento principal.
- Divida o programa em funções ou métodos e mantenha um menu em execução até a opção de saída.
- Antes de codificar, desenhe a estrutura e responda às questões de raciocínio.
- Em Python, anterior e proximo armazenam referências para outros objetos.

Invariantes que não podem ser quebrados
Lista dupla
- Se A.prox aponta para B, então B.ant deve apontar para A.
- O primeiro nó possui ant igual a None em Python.
- O último nó possui prox igual a None em Python.
- Em uma lista vazia, inicio e fim não apontam para nós.

Atividade 1 - Historico de navegação de páginas
Tipo de estrutura Lista duplamente encadeada
Situação profissional Um navegador precisa permitir que o usuário avance e volte pelas páginas visitadas. A
posição atual pode mover-se nos dois sentidos sem reconstruir o histórico.

base : 
class Pagina:
def __init__(self, url, titulo):
self.url = url
self.titulo = titulo
self.anterior = None
self.proximo = None

Funcionalidades obrigatórias
* Visitar uma nova página e inseri-la depois da página atual.
* Apagar o histórico que estava à frente quando uma nova página for visitada após usar Voltar.
* Voltar uma página, quando houver anterior.
* Avançar uma página, quando houver próximo.
* Exibir a página atual e o histórico do início ao fim.
* Exibir o histórico do fim ao início.

Testes obrigatórios
- Histórico vazio.
- Histórico com uma página.
- Voltar a partir da primeira página.
- Avançar a partir da última.
- Voltar e depois visitar uma página diferente.

Antes de programar
1. Quais referências mudam quando a nova página é inserida?
2. Por que o histórico à frente deve ser removido após uma nova navegação?
3. Quando inicio, fim e atual apontam para o mesmo nó?

Atividade 2 - Playlist editável
Situação profissional Um serviço de música permite navegar para a faixa anterior ou seguinte, inserir
músicas em posições específicas e retirar faixas sem perder a sequência.

base: 
class Musica:
def __init__(self, codigo, titulo, artista,
duracao):
self.codigo = codigo
self.titulo = titulo
self.artista = artista
self.duracao = duracao
self.anterior = None
self.proximo = None

Funcionalidades obrigatórias
1. Adicionar música ao final.
2. Inserir uma música antes de um código informado.
3. Inserir uma música depois de um código informado.
4. Listar do início ao fim e do fim ao início.
5. Buscar uma música pelo código.
6. Remover uma música pelo código.
7. Mover uma música existente para o início.
8. Calcular a duração total.

Testes obrigatórios
- Inserir antes da primeira e depois da última música.
- Remover a única música.
- Remover duas músicas consecutivas.
- Mover a primeira música para o início.
- Pesquisar código inexistente.

Antes de programar
1. Quantas ligações podem mudar ao remover um nó do meio?
2. Como reconhecer a remoção da primeira ou da última música?
3. Por que mover um nó não exige copiar todos os seus dados?
