# 📦 SmartStock — Sistema de Consulta e Organização de Produtos

O **SmartStock** é um sistema desenvolvido para gerenciamento, busca e ordenação de catálogos de produtos, com instrumentação interna para análise empírica de algoritmos clássicos de Ciência da Computação (contagem de operações e tempo de execução).
