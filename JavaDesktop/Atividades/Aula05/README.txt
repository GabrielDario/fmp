PROJETO: EstruturasDeSelecao

Projeto Java para a atividade de Estruturas de Seleção.
As classes utilizam a classe Teclado para entrada de dados pelo teclado.

Classes:
- Teclado
- Pessoa
- Teste até Teste12

Observacao:
Os exemplos foram organizados com base no material PDF enviado e nos
exemplos/codigos fornecidos na conversa. Como o material enviado apresenta
os conceitos e exemplos de IF, ELSE IF, SWITCH/CASE e metodos, mas nao
contém uma lista textual completa dos 12 enunciados, alguns Teste foram
montados como exemplos equivalentes para completar o projeto.

Para usar no BlueJ:
1. Crie/abra um projeto chamado EstruturasDeSelecao.
2. Copie todos os arquivos .java da pasta src para o projeto.
3. Compile.
4. Execute cada classe Teste pelo metodo main.
